# Netflix-Data-Analysis
The analysis of 8000+ titles shows Movies lead with 70% share vs 30% TV Shows, US is the top producer, content addition peaked in 2019-20, and Dramas with TV-MA rating dominate the library, highlighting Netflix's focus on mature, drama-driven content.
# About
This Netflix dashboard, built in Power BI, analyzes 8000+ titles to uncover content trends. It reveals Movies dominate (70%), US leads production, and Dramas with TV-MA ratings are key focus areas, guiding Netflix's Original content strategy.
# Tools
Power BI Desktop,Power Query,DAX,Excel (Data Cleaning),Netflix Dataset
